🎯 Mục tiêu đồ án

Xây dựng hệ thống phân loại tin nhắn email/SMS thành Spam hoặc Ham (không spam) sử dụng 7 mô hình Machine Learning + Deep Learning, so sánh hiệu suất và đóng gói thành ứng dụng web hoàn chỉnh.

🧠 Các mô hình được sử dụng

LoạiMô hìnhĐặc điểm
MLK-Nearest NeighborsPhân loại theo k láng giềng gần nhất
MLNaive BayesXác suất theo định lý Bayes, nhanh, hiệu quả với text
MLDecision TreeCây quyết định, dễ hiểu, dễ giải thích
MLKMeans (k=2)Phân cụm không giám sát, gán nhãn theo majority vote
MLSVM (LinearSVC)Tìm siêu phẳng tối ưu phân tách 2 lớp
DLLSTMMạng nơ-ron hồi quy, học ngữ cảnh tuần tự
DLDistilBERTFine-tune Transformer pretrained, hiện đại nhất

⚙️ Quy trình hoạt động

  1. Notebook training: notebooks/01_train_models.ipynb đọc data/spam.csv, tiền xử lý, train cả 7 mô hình, đánh giá và lưu các file model vào thư mục models/.
  2. Flask app: load các model đã lưu, expose REST API /api/predict và 4 trang web giao diện cho người dùng cuối.
  3. SQLite: lưu lại lịch sử mọi lần dự đoán để tra cứu.

▶️ Cài đặt và chạy

# 1. Cài thư viện
pip install -r requirements.txt

# 2. Train mô hình (mở Jupyter và chạy)
jupyter notebook notebooks/01_train_models.ipynb
# (Chạy tất cả các cell, mất ~5-15 phút trên CPU,
#  riêng DistilBERT khuyến khích chạy trên Google Colab có GPU)

# 3. Chạy web
python run.py
# Mở http://127.0.0.1:5000 trong trình duyệt
